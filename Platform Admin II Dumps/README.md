Platform Administrator II Practice Exam
========================================

Practice quiz for the Salesforce Certified Platform Administrator II (Advanced Administrator, exam code Plat-Admn-301) certification. Part of the [Practice-Exams](../) collection.

**Live app:** https://nathanofgod-ui.github.io/Practice-Exams/Platform%20Admin%20II%20Dumps/index.html

## What's in here

188 original, self-written practice questions organized under the exam guide's own 7 official content categories: Security and Access (20%), Process Automation (20%), Objects and Applications (19%), Data and Analytics Management (13%), Cloud Applications (11%), Auditing and Monitoring (10%), Environment Management and Deployment (7%). Every question includes a full explanation and links to the Salesforce Help / Trailhead article its answer is based on.

**These are not real exam questions** — see the repo-level [README](../README.md) for the full disclaimer.

## Features

- Practice by category or across the full 188-question bank
- A certification-weighted score at the end of a round, mirroring how Salesforce actually weights each official category instead of a flat percentage
- Export results as PDF or Word
- Runs entirely client-side — no account, no server, no data collection; progress is saved locally in your browser via `localStorage`

## Running it locally

Static site, no build step or dependencies. Open `index.html` directly in a browser, or serve this folder with any static file server.

Content is reviewed and corrected on an ongoing basis — if you spot an error, please open an issue.
