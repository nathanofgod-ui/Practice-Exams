Practice-Exams
==============

A collection of self-study practice quizzes for Salesforce certification exams. Each subfolder is a standalone practice app for one certification.

## Exams

- **[Platform Administrator II](./Platform%20Admin%20II%20Dumps/)** — practice for the Salesforce Certified Platform Administrator II (Advanced Administrator, exam code Plat-Admn-301) exam. [Live app ↗](https://nathanofgod-ui.github.io/Practice-Exams/Platform%20Admin%20II%20Dumps/index.html)

More exams will be added here over time.

## About these apps

- Static HTML/CSS/JS, no backend, no accounts, no data collection — progress is saved locally in your browser only
- Every question links to the Salesforce Help / Trailhead article backing its answer
- **None of these are real exam questions.** They're written from scratch to test the same skills and concepts each exam guide describes, not reproductions, paraphrases, or memorized copies of actual exam content. Salesforce's certification agreement prohibits sharing real exam questions, and nothing in this repo is that.
